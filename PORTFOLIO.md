## Featured projects

### 1. RGB Field Image Analysis
**Repository:** [Soil-Quality-MONITORING](https://github.com/gayatrinaram/Soil-Quality-MONITORING)

An OpenCV and NumPy notebook that processes a field image and visualises an exploratory red-blue colour index. The notebook explicitly documents why this is not scientific NDVI: standard RGB images do not contain the near-infrared band required for true NDVI.

**Skills demonstrated:** Python, OpenCV, NumPy, image processing, visualisation.

### 2. BMI Category Classification
**Repository:** [Diabetes-Prediction-using-Python-and-Logistic-Regression](https://github.com/gayatrinaram/Diabetes-Prediction-using-Python-and-Logistic-Regression)

A scikit-learn classification workflow for predicting BMI categories from tabular data. The notebook now uses a preprocessing pipeline, stratified train/test split, Logistic Regression, and class-wise evaluation.

**Skills demonstrated:** Python, pandas, scikit-learn, preprocessing, classification, model evaluation.

> The historical repository name is retained for continuity. The implemented target is BMI category, not diabetes diagnosis.
