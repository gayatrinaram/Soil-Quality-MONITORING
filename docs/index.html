RGB Field Image Explorer

An image-processing workflow that analyses a field image and visualises an exploratory red-blue colour index using OpenCV and NumPy.

WHAT IT DOES

Upload an image, calculate (R − B) / (R + B), inspect the colour-mapped output and download the visualisation. A local Streamlit interface makes the workflow easy to try.

REAL-WORLD DIRECTION

A foundation for a validated remote-sensing workflow using calibrated red and NIR bands, field observations and true NDVI.

Python · OpenCV · NumPy · Streamlit · Image Processing

MACHINE LEARNINGREPRODUCIBLE PIPELINE

BMI Category Classification

A supervised-learning workflow that classifies tabular records into BMI categories with Logistic Regression and scikit-learn.

WHAT IT DOES

Preprocesses numeric and categorical features, trains a model, reports class-wise metrics and saves a reusable pipeline for batch predictions.

REAL-WORLD DIRECTION

A learning baseline for studying data quality, class imbalance, model evaluation and responsible use of classification systems.

Python · pandas · scikit-learn · Logistic Regression · Model Evaluation

The historical repository name is retained for continuity. The implemented target is BMI category, not diabetes diagnosis. This is not a medical tool.
