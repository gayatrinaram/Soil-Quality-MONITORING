# Gayatri Naram — Portfolio Website

This is the source for my personal AI and machine-learning portfolio website.

## Preview

The site is published with GitHub Pages from the `docs/` folder of this repository.

## Sections

- About and technical interests
- Selected projects with source-code links and practical context
- Experience and education
- Contact and GitHub links

## Tech

HTML, CSS and vanilla JavaScript. Responsive layout with no build step.

## Local preview

Open `index.html` in a browser, or run a local static server from this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publishing

In the repository settings, open **Pages**, select **Deploy from a branch**, choose the `main` branch and the `/docs` folder, then save. GitHub Pages will publish the portfolio at the repository's project-site URL.

## Accuracy note

Only repositories with inspectable source code are listed as featured projects. Other academic projects can be added once their original repositories and files are available.
